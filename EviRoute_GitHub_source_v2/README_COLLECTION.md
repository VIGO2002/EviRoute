# EviRoute Source Collection

This archive collects selected source files from
the EviRoute research and edge-deployment projects.

## research_7b
Original DINOv3-7B/Mid20 research implementation,
including training, evaluation, evidence auditing,
and selected experimental analysis scripts.

## edge_vitb
DINOv3 ViT-B/16 Mid6 clean PyTorch inference
implementation and configuration.

## Important
- This is a source-code collection, not yet a
  polished or fully self-contained GitHub repository.
- Model checkpoints are intentionally excluded.
- Datasets and feature caches are excluded.
- Original paths and imports may require refactoring.
- Audit dependencies, attribution, and configuration
  before public release.
